# Guide utilisateur

1. Connectez-vous avec votre compte. L'accès aux modules dépend de votre rôle.
2. Créez les catégories, fournisseurs puis les médicaments. Ajoutez une photo si nécessaire et renseignez les prix et seuils d'alerte.
3. Pour approvisionner : créez une commande, ajoutez des lignes, validez-la, puis réceptionnez les quantités réelles en renseignant numéro de lot et date de péremption. Le stock est modifié uniquement à la réception.
4. Consultez le module Stock pour suivre les lots, mouvements, alertes et inventaires.
5. À la caisse, sélectionnez les médicaments, vérifiez le panier, le client et le mode de paiement puis confirmez. Le reçu PDF s'ouvre après validation.
6. Retrouvez les ventes dans l'historique. Un retour doit être enregistré depuis la vente d'origine avec un motif. La remise en stock n'est autorisée que si le lot est encore valide et non bloqué.
7. Le tableau de bord et les rapports présentent les indicateurs calculés depuis les transactions enregistrées.
8. L'administrateur crée les comptes et attribue les rôles. Consultez le journal d'audit pour les opérations sensibles.

Ne saisissez jamais de données réelles de patients dans une base de démonstration. Avant usage professionnel, vérifiez les obligations réglementaires locales et configurez les sauvegardes.
